# テーマ

content に `theme` を1行書くと、基本の CSS のあとにテーマの CSS が足されます。
部品（`K.〜`）の書きかたは変わりません。

```js
const CONTENT = {
  theme: 'cool',
  tones: ['white', 'sage', 'teal', 'pink', 'magenta'],   // 章ごとの背景色（省略可）
  labels: { next: 'Next', prev: 'Back', start: 'Start', end: 'Fin' },
  …
};
```

見本: `node build.mjs content/example-cool.js`

## cool — ベタ塗りの色面・巨大な見出し・古い OS の窓

[typesafe.ai](https://typesafe.ai/) の画面を手本にしたトーンです。
発表資料を「かわいく」ではなく「かっこよく」見せたいときに使います。

> 2026-10-05 までの cool は「黒背景・藍1色」でした。上書きしています（旧版は git の `4b4007a`）。

### 決まり

| | 決まり | 理由 |
|---|---|---|
| 1 | 背景は**1色のベタ塗り**。章ごとに色を替える。グラデーションは使わない | 色面そのものが「いま何章か」を伝える |
| 2 | 文字は**墨色1色**。色で強調しない | 背景が何色でも読める。強調の手段を増やさない |
| 3 | 見出しは**巨大に、字間も行間も詰めて、中央寄せ**。扉の題名は必ず1行 | 1画面1メッセージが、遠くからでも読める |
| 4 | 箱は「**窓**」：角は直角、1px の黒い線、黒いタイトルバーに等幅の白文字、硬い影 | 部品の種類が増えても、同じ顔になる |
| 5 | 小さい字（ラベル・注記・日付）は**等幅**。選んだもの・押したものは**紫紅** | 本文と注記が、書体だけで見分けられる |

強調のしかたは3つだけです。見出しは**下線**、ラベルは**白黒反転**、本文は**朱色のマーカー**（`K.memo` の `<b>`）。

### 色

| `tones` に書く名前 | 色 | |
|---|---|---|
| `white` | `#FFFFFF` | 表紙・締め |
| `sage` | `#ABBAB9` | 灰緑。説明の章 |
| `teal` | `#09AEA1` | 青緑 |
| `pink` | `#F386A1` | 桃 |
| `magenta` | `#D45BB6` | 紫紅。選択・ホバーの色でもある |

墨色は `#1E1E1E`（濃い）と `#323434`（見出し・本文）、マーカーは `#F5505D`。
`tones` を省くと、章の順に white → sage → pink → teal → magenta と回ります。
基本のトーンのまま `tones` だけ書いても、`body[data-tone]` が付くだけで見た目は変わりません。

### テーマが切り替えるもの

| | 基本 | cool |
|---|---|---|
| 背景 | 空色のグラデーションと雲 | 章ごとのベタ塗り |
| 書体 | M PLUS Rounded 1c（太い丸ゴシック） | Inter Tight + Zen Kaku Gothic New ／ 等幅は JetBrains Mono + DotGothic16 |
| 見出し | 左寄せ。強調は白抜き＋色の影 | 中央寄せ・巨大。強調は下線 |
| 上のラベル（`tag`） | 白い丸い札 | 黒地に等幅の白文字。扉では出さない |
| 箱 | 白・丸み26px・影 | 窓（直角・1px の線・硬い影）。`K.cards` の `k` がタイトルバーになる |
| `K.nums` の `tone` | ok=緑 / dn=赤 / st=橙 | どれも墨色。`dn` はグレーの面で薄く |
| `K.quote` / `K.memo` | 箱 | 箱にしない。左に細い線。`K.memo` の `<b>` は朱色のマーカー |
| `K.ask` / `K.callout` | 黄色い吹き出し・揺れる | 窓 / 下線つきの大きな字 |
| 解説（◆）の面 | 白い吹き出し | 「Note 1.1」という名前の窓 |
| 章の扉 | `num` が大きい | `num` は黒い小さなラベル、`title` が巨大。**字数に合わせて1行に収まる大きさになる** |
| ボタン | 丸い・跳ねる | 白い札の Back と、黒い Next |
| 音 | `sound:true` で高い「キラキラ」 | `sound:true` で低く短い「トッ」（`'cool'`） |
| 星の瞬き・揺れ | ある | 出ない |

音だけ別にしたいときは、`sound:'soft'`（従来の音）や `'chip'` を名指しします。

### 自分の図を足すとき

`extra.css` で図を描くときも、決まりに合わせます。

- 箱は `background:var(--win); border:1px solid var(--ink); box-shadow:var(--sh)`
- タイトルバーは `background:var(--ink); color:#fff; font-family:var(--mono)`
- 小さい字は `font-family:var(--mono)`、色は `var(--ink)` か `var(--ink2)` だけ
- 1箇所だけ目立たせたいときは `var(--hi)`（朱色）。それ以外の色は足さない
- 太さはテーマが `!important` で 400 に揃えている。太くしたい箇所は `font-weight:500!important`

### キャラクター

このトーンでは、キャラクターは置かないほうが合います。`guide` を省くと、左下は ◆ のボタンになります。

## テーマを足す

`src/themes/<name>.css` を置くと `theme:'<name>'` で使えます。
1行目を `/* fonts: <Google Fonts の URL> */` にすると、その書体も読み込まれます。
