# テーマ

content に `theme` を1行書くと、基本の CSS のあとにテーマの CSS が足されます。
部品（`K.〜`）の書きかたは変わりません。

```js
const CONTENT = {
  theme: 'cool',
  labels: { next: 'Next →', prev: 'Back', start: 'Start →', end: 'Fin' },
  …
};
```

見本: `node build.mjs content/example-cool.js`

## cool — 黒背景・細い書体・差し色1つ

海外のプロダクト（Linear / Vercel / Raycast など）の画面を手本にしたトーンです。
発表資料を「かわいく」ではなく「静かに」見せたいときに使います。

### 決まり

| | 決まり | 理由 |
|---|---|---|
| 1 | 色は 黒・白・グレーと、差し色1つ。**緑と赤は使わない** | 緑＝良い、赤＝悪い は説明くさくなる。良いは白、悪いはグレーで足りる |
| 2 | 面は白くしない。背景より少し明るいグレーと、細い線で分ける | 黒の上の白い面は、そこだけが主役になる |
| 3 | 白い面は「押すもの」（つぎへ）にだけ使う | 白が1箇所なら、次に何を押すかで迷わない |
| 4 | 書体は細く、太字は 500 まで。揺れ・跳ね・星は止める | 動き続けるものがあると、読む目が落ち着かない |

### テーマが切り替えるもの

| | 基本 | cool |
|---|---|---|
| 背景 | 空色のグラデーションと雲 | 黒。右上に差し色の淡い光 |
| 書体 | M PLUS Rounded 1c（太い丸ゴシック） | Geist + Zen Kaku Gothic New（細い） |
| 見出しの強調 | 白抜き＋色の影 | 差し色の文字 |
| 箱 | 白・丸み26px・影 | 黒に近いグレー・丸み14px・細い線 |
| `K.nums` の `tone` | ok=緑 / dn=赤 / st=橙 | ok=白 / dn・st=グレー |
| `K.ask` / `K.callout` | 黄色い吹き出し・揺れる | 差し色の細い枠 / 上に線を引いた大きな文字 |
| 解説（◆）の面 | 白い吹き出し | 半透明のグレー（後ろがぼける）。左上に NOTE |
| 章の扉 | 中央寄せ。`num` が大きい | 左寄せ。`num` は小さな肩書き、`title` が主役 |
| 音 | `sound:true` で高い「キラキラ」 | `sound:true` で低く短い「トッ」（`'cool'`） |
| 星の瞬き | 出る | 出ない |

音だけ別にしたいときは、`sound:'soft'`（従来の音）や `'chip'` を名指しします。
逆に、基本のトーンのまま `sound:'cool'` だけ使うこともできます。

### 差し色を変える

`content/<name>.extra.css` で2つの変数を上書きします。

```css
:root{
  --acc:#8B93FF;      /* 文字と細い線 */
  --accFill:#5E6AD2;  /* 面を塗るとき。--acc より一段暗く */
}
```

### 自分の図を足すとき

`extra.css` で図を描くときも、上の決まりに合わせます。

- 色は `var(--acc)` / `var(--accFill)` / `#fff` / `var(--ink2)` / `var(--line)` から選ぶ
- 箱は `background:var(--card)`、`box-shadow:var(--shS)`（細い線になる）、`border-radius:14px`
- 太さはテーマが `!important` で 400 に揃えている。太くしたい箇所は `font-weight:500!important`

### キャラクター

基本のキャラクターは絵柄が合いません。`guide` を省くと ◆ のボタンになります。
入れる場合は、線の少ない絵か、落ち着いた色のアニメ調が合います。
黒地で沈まないよう、テーマが細い白の縁と差し色の光を足します。

## テーマを足す

`src/themes/<name>.css` を置くと `theme:'<name>'` で使えます。
1行目を `/* fonts: <Google Fonts の URL> */` にすると、その書体も読み込まれます。
